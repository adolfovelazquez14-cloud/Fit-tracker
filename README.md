# GymTrack — Macros & Entrenamiento

Aplicación web para registrar macros, alimentos, comidas y entrenamientos.

## Publicar en GitHub Pages

1. Sube `index.html`, `style.css` y `app.js` a la raíz del repositorio.
2. Ve a **Settings → Pages**.
3. Selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda y abre la URL que GitHub Pages genere.

Los datos de la aplicación se guardan localmente en el navegador mediante `localStorage`.
